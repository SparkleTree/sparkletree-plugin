# SparkleTree plugin: orientation for agents

You are in the SparkleTree plugin repository. It packages skills, two agents, two hooks and one remote MCP server declaration for Claude Code, Codex, ChatGPT, Gemini CLI, Cursor and any MCP client. The server itself is not in this repo; it runs at `https://app.sparkletree.io/api/mcp` and is owned by the SparkleTree monorepo.

## If you are here to use SparkleTree

Read `skills/sparkletree/SKILL.md` first. It carries the rules that every other skill assumes: read `mosaic://capabilities`, read before write, confirm before publish, deploy, delete or credit spend. `skills/sparkletree/references/tools.md` is the tool table.

## If you are here to change the plugin

Layout (only `plugin.json` and `marketplace.json` live in `.claude-plugin/`; everything else sits at the root):

- `.claude-plugin/plugin.json`: manifest. `name` is `sparkletree` and must not change (it namespaces skills and agents, and scopes MCP tool names to `mcp__plugin_sparkletree_sparkletree__<tool>`).
- `.claude-plugin/marketplace.json`: one-plugin marketplace with `source: "./"`.
- `.mcp.json`: the remote server. Loads as `plugin:sparkletree:sparkletree`, so its tools are `mcp__plugin_sparkletree_sparkletree__<tool>`. When the user already has SparkleTree as a claude.ai connector for the same URL, Claude Code suppresses the plugin's copy as a duplicate (debug log: "Lazy dedup") and the tools appear under the connector's own server id (`mcp__<connector-id>__<tool>`).
- `skills/<name>/SKILL.md` plus `references/`: eight model-invocable skills and four user-invoked commands (`setup`, `launch`, `digest`, `status`, all `disable-model-invocation: true`). Descriptions open with "SparkleTree" plus a campaign noun and stay between 200 and 400 characters; bodies stay under 500 lines; long material goes in `references/`.
- `agents/`: `campaign-reviewer` and `analytics-digest`, both read-only via `disallowedTools` listing every write tool under both the plugin-scoped and the bare server name.
- `hooks/hooks.json`, `scripts/*.sh`: POSIX sh, no dependencies. `check-connector.sh` is silent on success and always exits 0. `spend-guard.sh` returns a PreToolUse `ask` decision for spend and destructive actions and never blocks reads. The matcher is `mcp__.*__(generate_campaign|render_video|video_commission|manage_campaigns)$`, wide on the server segment on purpose: the same four tools arrive as the plugin-scoped name, a hand-added `mcp__sparkletree__` server, or a claude.ai connector id, and the script keys on the tool-name suffix. The narrower `mcp__(plugin_sparkletree_)?sparkletree__(...)` form misses the connector case.
- `evals/`: one case per model-invocable skill in the `claude plugin eval` layout (`prompt.md` + `graders/*.md`), plus `run-smoke.sh`, a `claude -p` runner for hosts where `plugin eval` is not enabled.
- `server.json`: official MCP registry manifest (`io.sparkletree/sparkletree`).
- `gemini-extension.json`: Gemini CLI manifest; points at the same server and uses this file as context.
- `submissions/`: one paste-ready file per directory venue plus the ordered checklist in `submissions/README.md`; `submissions/docker/` holds the Docker catalog skeleton. Nothing in it is submitted by agents without the rulings named in the checklist.
- `openai/`: the skills-only bundle for the OpenAI plugin submission, generated by `scripts/build-openai-bundle.sh`. Edit `skills/` and regenerate; do not edit `openai/` by hand.

## Tool names

The skills are written for the 15-tool default surface: the 12 tools live today plus `query_brand`, `query_surfaces` and `query_video_commissions`, which a pending server release splits out of `manage_brand`, `manage_surfaces` and `video_commission`. Until that release ships, the read actions still live on the manage tools (`manage_brand action=get`, `manage_surfaces operation=list_surfaces|get_surface|list_zones`, `video_commission action=list|get`). Verify against `mosaic/lib/mcp/toolGates.ts` in the monorepo before changing a tool name here.

## Checks before a commit

```sh
claude plugin validate --strict .
claude plugin validate --strict skills
claude plugin validate --strict agents
sh -n scripts/*.sh
printf '{"tool_name":"mcp__plugin_sparkletree_sparkletree__generate_campaign","tool_input":{"mode":"start"}}' | sh scripts/spend-guard.sh
scripts/build-openai-bundle.sh && git diff --exit-code openai/
```

Writing rules for anything a person reads: plain sentences, sentence-case headings, no em dashes, no marketing adjectives, say what happens and who pays for what.
