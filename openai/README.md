# OpenAI skills bundle

Generated by `scripts/build-openai-bundle.sh` from `../skills` and `../agents`. Upload this directory (zipped) in the OpenAI plugin submission portal as a skills-only plugin, or attach it to the "With MCP" submission that points at `https://app.sparkletree.io/api/mcp`. Host-specific wording is replaced with "the model"; commands and agents are folded into skills; hooks, marketplace and MCP config are not included because the portal does not run them.
